Firebase Setup

Firestore database configuration

Config is hardcoded in this file

Your Firebase config is baked into admin.html and works on every device automatically — no re-entering needed. The form below lets you override with different values if ever needed.

1 Create Firebase Project

Go to console.firebase.google.com → Add project → Firestore Database → Create in test mode.

2 Get Config & Enter Below

Project Settings → Your apps → Web → copy the config values.

Lock Firebase config (prevent accidental changes)

3 Firestore Rules — paste these (auth-secured)

These rules allow anyone to read (your portfolio visitors) but only authenticated users to write (only you, after signing in to admin).

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
✓ Secure: request.auth != null means only users signed in via Firebase Auth can write. Random visitors cannot modify your portfolio data even if they find your Firebase config.
